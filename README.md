# 🛍️ Full Stack E-Commerce Website

A full-stack e-commerce web application developed using modern frontend and backend technologies. The project focuses on building a responsive shopping experience with frontend and backend integration.

## 🚀 Technologies Used

### Frontend

* React.js
* JavaScript
* HTML5
* CSS3
* Bootstrap

### Backend

* Java
* Spring Boot
* REST APIs

### Database

* MySQL

### Tools

* VS Code
* Eclipse
* Postman
* Git & GitHub

## ✨ Features

* Responsive user interface.
* Product listing and display.
* Frontend and backend integration.
* REST API communication.
* MySQL database integration.
* User registration and login.
* Shopping cart functionality.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Siddharth-099/Full-Stack-Website.git
```

### 2. Navigate to Project Folder

```bash
cd Full-Stack-Website
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

Open the local URL displayed in your terminal to view the application.

## 🔧 Backend Setup

The backend is developed using Java and Spring Boot.

1. Open the Spring Boot project in Eclipse.
2. Configure the MySQL database connection.
3. Update database credentials in `application.properties`.
4. Run the Spring Boot application.
5. Connect the React frontend with backend REST APIs.

MySQL is used for database management and storing application data.
